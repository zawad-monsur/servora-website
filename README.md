# Servora website

Static marketing site (HTML, CSS, JS — no build step). Open `index.html` or serve the folder.

- Contact details: set `CONTACT.whatsapp` and `CONTACT.email` at the top of `assets/site.js`.
- Product images in `assets/img/` are deliberately cropped fragments at moderate resolution.
  Never publish full-screen captures of the product here.
- `robots.txt` blocks AI training crawlers.

Deploy: GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/root`).
